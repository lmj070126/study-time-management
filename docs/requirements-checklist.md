# 学生学习时间管理与效率分析系统——需求验收清单

## 一、项目基本信息
- 项目编号：20
- 项目名称：学生学习时间管理与效率分析系统
- 开发形式：Web应用
- 技术方案：Vue 3 + FastAPI + MySQL + 华为云FunctionGraph
- 第一周负责人：本人
- 最终提交：源代码、README、功能演示视频、AI辅助记录

## 二、功能验收准则

### R01 用户身份与权限
系统具有学生、班主任、管理员三种角色。三类用户登录后进入对应页面。

### R02 学习任务管理
学生可以创建、查看、修改和删除自己的任务，不得操作他人的任务。

### R03 专注与休息计时
默认专注25分钟、休息5分钟；支持修改专注分钟数。

### R04 专注记录
一次专注正常结束生成一条记录，包含科目、开始时间、结束时间、分钟数、自评1至5分。取消或放弃不产生有效学习记录。

### R05 数据校验
学习分钟必须大于0；结束时间晚于开始时间；自评分数只能为1至5。

### R06 幂等与原子性
同一专注会话重复提交不能重复增加分钟；保存操作要么全部成功，要么不产生记录。

### R07 科目时长统计
同一天数学学习25分钟两次，数学累计50分钟。

### R08 科目占比
科目占比=该科目分钟数/全部分钟数；只有数学时数学占比为100%。占比必须由华为云函数计算并在页面展示。

### R09 学习周报
周报差值=本周总分钟-上周总分钟，差值允许为负数。

### R10 连续学习勋章
连续7个自然日，每日至少一条学习记录，可获得连续学习勋章；中断一天后重新计算连续周期。

### R11 休息提醒
一天内累计学习达到180分钟时提醒休息一次，之后继续学习不得重复提醒。

### R12 小班隐私保护
班主任仅能查看人数不少于5人的所管班级汇总和允许的匿名时长榜，不得查看学生个人明细；人数不足5人不得展示班级个人分钟数。学生本人仍可查看自己的学习数据。

### R13 匿名学习榜
允许展示时，匿名榜只显示化名与本周分钟，不显示真实姓名和个人明细。

### R14 管理员功能
管理员维护科目及勋章规则，不得代学生补记学习时长。

### R15 云函数定时任务
配置每日一次的华为云定时触发器，检查是否连续7日学习；手工触发与定时触发结果一致，同一连续周期重复触发只颁发一次。

### R16 下周预测（进阶）
预测使用最近4个已结束完整周的平均分钟数，按要求四舍五入；100、120、80、100分钟预测为100分钟。

### R17 预测范围（进阶）
不得将当前未结束周计入最近4个完整周的平均值。

### R18 周报导出（进阶）
周报仅含本人数据；4人班学生仍能导出本人周报。

### R19 导出一致性（进阶）
导出文件必须包含最近4周分钟、预测值、较上周差值，与页面数据一致。

### R20 初始化数据
至少建立1个6人班级和1个4人班级，包含学生、班主任、管理员和科目。6人班准备最近4个完整周100、120、80、100分钟的可核对记录。

### R21 云资源
仅使用华为云函数工作流免费额度，不开通付费套餐，访问密钥不提交到仓库。

### R22 交付要求
提交源代码、README、功能演示视频和3条AI辅助使用记录；进阶部分准备不少于10组输入与预期输出。

## 四、四条必须通过的越权测试

- [ ] P01 学生尝试修改另一学生记录：返回403，不修改数据。
- [ ] P02 学生尝试访问其他班级的受限数据：返回403，不泄露数据。
- [ ] P03 班主任直接请求学生个人记录：返回403，不返回个人明细。
- [ ] P04 管理员尝试代学生补记时长：返回403，不产生新记录。

以上权限必须在后端接口实现，不能仅通过隐藏前端按钮限制。
